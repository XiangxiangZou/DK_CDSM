# Project Assets

- `models/`: project-level MuJoCo XML source models.
- `references/`: local literature and reference material.

The correctly spelled cable model filename is:

```text
assets/models/multi_joint_cable_driven_space_robot.xml
```

`src/cdsm/assets/` contains the package-local copy needed when the reusable
CDSM package is migrated to another project.
