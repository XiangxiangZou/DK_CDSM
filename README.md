# Deep Koopman Dynamics & Control: From Theory to Space Robotics

本仓库旨在梳理深度 Koopman 算子（Deep Koopman Operator）在动力学建模与控制领域的核心文献，记录从基础理论到通用控制框架，再到空间机器人（Space Robotics）工程落地的演进过程。项目使用 **MuJoCo** 物理引擎对 **绳驱空间机械臂（Cable-Driven Space Manipulator, CDSM）** 进行仿真建模与控制算法验证。

### 核心演进逻辑

1. **[Lusch 2018]**：确立了利用自编码器发现 Koopman 特征函数的范式，解决了频率随能量变化的动力学演化问题。
2. **[Shi 2022]**：将研究重点从单纯的「预测」转向「控制」，提出了一套能直接对接线性控制理论（LQR）的全系统线性化架构。
3. **[Mao 2024]**：将上述理论应用于自由浮动空间机器人，并引入鲁棒补偿机制（DOB），验证了在算力受限与有扰动环境下的可行性。

## 🛠 研究方案总结：深度 Koopman 智能控制框架

一套完整、易扩展的 Deep Koopman 研究方案通常包含以下模块：

### 1. 数据驱动建模模块 (Modeling)

* **特征提取**：使用深度自编码器将非线性状态 $x$ 映射至高维潜空间 $z$。
* **算子学习**：在潜空间学习线性转移矩阵 $A$ 与控制矩阵 $B$。
* **损失函数**：结合重构损失、线性演化损失与多步预测损失（K-steps loss）。

### 2. 在线优化控制模块 (Control)

* **线性 MPC**：在隐空间中利用 $z_{k+1} = Az_k + Bu_k$ 进行快速路径规划。
* **低功耗计算**：将非线性优化转化为凸二次规划 (QP)，适合星载计算。

### 3. 鲁棒补偿模块 (Robustness)

* **扰动观测器 (DOB)**：估计 Koopman 模型的近似误差及环境外扰。
* **实时修正**：将估计的扰动量前馈补偿至控制输入 $u$ 中。

## 🚀 针对「绳驱空间机械臂 (CDSM)」的未来研究方向

绳驱机械臂具有独特的物理约束（如绳索单边受力、时变刚度），以下是基于上述文献的创新切入点：

### 🔹 创新点 1：带物理约束的 Koopman 嵌入

* **内容**：研究如何将绳索的「张力锥（Tension Cone）」约束直接映射到 Koopman 潜空间。
* **价值**：使线性 MPC 求解出的结果天然满足绳索不松弛条件。

### 🔹 创新点 2：处理柔性-位置双尺度动力学

* **内容**：借鉴 Lusch 的辅助网络，构建一个能同时解耦「大尺度刚体运动」与「高频绳索振动」的 Koopman 算子。
* **价值**：实现对绳驱机械臂残余振动的主动抑制。

### 🔹 创新点 3：跨构型自适应 Koopman 模型

* **内容**：针对机械臂伸缩导致的几何参数变化，开发参数化 Koopman 算子。
* **价值**：无需重新训练，即可实现全工作空间的精准控制。

## 🔬 关键技术实现

### 拮抗绳驱映射器

核心算法在 `mujoco_cdsm_antagonistic_pd_tracking.py` 中实现：

- **同侧对合并**：8根绳索合并为4组（F1p, F1m, F2p, F2m），每组两根绳索共享张力
- **闭式求解器**：在三种候选方案（仅正侧、仅负侧、双侧预紧）中选择最优，最小化残差同时将张力限制在 [F_preload, F_max] 范围内
- **在线绳索 Jacobian**：通过有限差分法在独立 MjData 副本上计算 J(q) ∈ ℝ^(8×nv)，避免递归回调

### 双重控制策略对比

| 维度       | 动力学控制                                     | 运动学控制                                  |
| :--------- | :--------------------------------------------- | :------------------------------------------ |
| 控制链路   | PD → τ → 拮抗映射 → 8绳张力 → MuJoCo 积分 | 位置规划 → 绳长反解 → 卷筒指令 → 写 qpos |
| 涉及物理量 | 力/质量/惯性/阻尼                              | 仅几何长度                                  |
| 跟踪精度   | 有 PD 过渡误差 + 绳驱几何退化误差              | 仅速率限幅残差（可接近0）                   |
| 适用范围   | 物理仿真验证                                   | 真机位置伺服等效                            |

### 物理模型特点

- **5 根连杆**，基座固定，4 个旋转关节（joint1≡joint2=qa, joint3≡joint4=qb → 2个自由度）
- **8 根绳索（4个拮抗对）** 驱动，spreader 横杆（0.6m）+ 主连杆机构
- 绳索张力 → tendon Jacobian → 关节广义力矩的完整物理链路
- 零重力（失重空间环境），RK4 积分器，dt=10ms，damping=2.0
